# Official Plugin packaging reference used by M5.1

M5.1 follows OpenAI's current Plugin packaging contract:

- installable packages use `.codex-plugin/plugin.json`;
- bundled Skills are stored in a plugin-root `skills/` directory;
- the plugin manifest points to that directory with `"skills": "./skills/"`;
- one plugin may contain a group of related Skills;
- repo-scoped/local marketplace distribution can point at a plugin folder.

Primary references reviewed on 2026-08-27:

- https://developers.openai.com/plugins/concepts/plugins
- https://developers.openai.com/plugins/build/skills
- https://developers.openai.com/plugins/build/plugins

The repository does not vendor or copy OpenAI documentation; this file records only the compatibility decisions M5.1 implements.
